# 🔥 flutter firebase-firestore database posts

A modern **Flutter** application with Firebase Authentication and dual database support.  
After login/signup, users can choose between **Firebase Realtime Database** and **Cloud Firestore** to manage posts with full CRUD and search functionality.

## ✨ Features

- 🔐 **Firebase Authentication** – Complete Login & Signup system
- 🧭 **Choice Screen** – Select between two databases after login
- 🔥 **Firebase Realtime Database** – Create, Read, Update, Delete & Search posts
- ☁️ **Cloud Firestore** – Create, Read, Update, Delete & Search posts
- ⚡ **Realtime Updates** – Instant data synchronization
- 🔍 **Search Functionality** – Quickly find posts
- ✏️ **Edit & Update** – Modify existing posts easily
- 🗑️ **Delete Posts** – Remove posts with confirmation
- 🎨 **Clean UI** – Simple and modern user interface
